A tiny Python program that writes one real-life patch note to `/output/entry.txt`: a single changelog line of at most 160 characters for a bug in human biology, in the terse register of a real release note — a memory leak where a song heard once in 2007 occupies storage permanently while today's grocery list expires in 90 seconds. The line was picked by drafting fourteen candidates and duelling them pairwise on the bounty judge's own criteria — a patch note that reads as comedy first, then whether the joke genuinely lands on first read, how true the release-note register is, how specific and recognisable the bug is, and whether every character works. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
